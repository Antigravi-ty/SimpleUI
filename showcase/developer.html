1. Container & Scale Policy

Developers must establish a root container bound to --ui-scale and --ui-safe-*. You may lock scale at 100%, listen to device pixel ratio, or let users adjust it via viewportEngine.setUserScale(number). SimpleUI provides standard APIs without enforcing policy.

Safe Area Margin is optional (defaults to 0%), but strongly recommended (strongly recommend) to guarantee zero clipping on notched and bordered displays.

2. Width Anchoring & 9-Point Grid

All dimensions and symmetric corner paddings scale strictly according to virtual canvas width (Wrender / 1280px), decoupled from height.

Macro compound containers anchor to the 3×3 9-point grid (e.g. 3-stage container at center). Contextual sub-components (such as .ui-dropdown__menu) anchor directly to their trigger button via CSS position: absolute; top: calc(100% + var(--ui-space-1)).

3. Content-Driven Container Capabilities (Layout Infection Pattern)

In hierarchical workflows (like Basic Transition or drilldowns), the outer host Container DOM node remains stable. Special paradigms (such as Live Preview or Floating Window) are declared by the active Content view and propagate upward to infect the Container with stateful layout attributes. When navigating away to standard views, the container cleanly reverts. 

import { viewportEngine } from 'simple-ui/core';

// Subscribe to virtual canvas metrics
viewportEngine.subscribe(({ scaleFactor, Wrender, Hrender, insets }) => {
  document.documentElement.style.setProperty('--ui-scale', scaleFactor);
});

Declarative Action Router Primitives

              UIRouter
            

            

              All interactions map to declarative action primitives in actions.json without per-element event listener bloat.
            

          

          

            
{
  "actions": {
    "menu.to_network": {
      "type": "drilldown_push",
      "hideSelector": "#menu-view-root",
      "showSelector": "#menu-view-network"
    },
    "window.toggle_minimize": {
      "type": "class_toggle",
      "targetSelector": "#floating-window",
      "className": "floating-window--minimized"
    }
  }
